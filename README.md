# 🧮 Projeto Calculadora

Uma calculadora simples com interface gráfica desenvolvida em **Python** utilizando a biblioteca **Tkinter**.

## ✨ Funcionalidades

-  Soma
-  Subtração
-  Multiplicação
-  Divisão
-  Resto da divisão
-  Limpar tela

## 🛠️ Tecnologias Utilizadas

- Python 3
- Tkinter

## 🚀 Como Executar

1. Certifique-se de ter o Python 3 instalado.
