# Projeto Calculadora de Notas

Calculadora de quantidade de notas para um determinado valor desenvolvida com **HTML**, **CSS** e **JavaScript**.

## Funcionalidades

* Converte um valor monetário digitado pelo usuário na menor quantidade possível de notas de 50, 20 e 10.
* Interface simples e intuitiva para interação rápida.

## Tecnologias

* JavaScript
* HTML
* CSS

## Como executar

1. Clone o repositório. Execute o comando abaixo para baixar a raiz do projeto:

```bash
git clone https://github.com/mateusoliveira3107/projetos.git
```

2. Entre na pasta raiz e navegue até o diretório onde este projeto está salvo
```bash
cd projetos/calculadoraNotas
```
