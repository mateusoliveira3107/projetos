# Projeto Calculadora de Notas

Calculadora de quantidade de notas para um determinado valor desenvolvida com **HTML**, **CSS** e **JavaScript**.

## Funcionalidades

* Converte um valor monetário digitado pelo usuário na menor quantidade possível de notas de 50, 20 e 10.
* Interface simples e intuitiva para interação rápida.

## Tecnologias

* JavaScript
* HTML
* CSS

## Como executar

1. Clone o repositório:

```bash
git clone https://github.com/Projetos/calculadoraNotas.git
```

2. Abra a pasta do projeto no seu editor de código (como o VSCode), ou abra o arquivo index.html diretamente no seu navegador de preferência, ou utilize a extensão Live Server para visualizar a aplicação.
