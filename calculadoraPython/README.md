# Projeto Calculadora

Calculadora com interface gráfica desenvolvida em **Python** utilizando **Tkinter**.

## Funcionalidades

* Soma
* Subtração
* Multiplicação
* Divisão
* Resto da divisão
* Limpar tela

## Tecnologias

* Python 3
* Tkinter

## Como executar

1. Tenha o **Python 3** instalado.
2. Clone o repositório:

```bash
git clone https://github.com/Projetos/Projeto_Calculadora.git
```
