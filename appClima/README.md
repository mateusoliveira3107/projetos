Projeto de um aplicativo de clima desenvolvido para praticar HTML, CSS e JavaScript, utilizando APIs para buscar informações meteorológicas.

O projeto está sendo desenvolvido de forma gradual, adicionando novas funcionalidades conforme os conhecimentos em JavaScript são aprendidos.

Funcionalidades
Pesquisa de clima por cidade
Busca automática da localização da cidade
Exibição do país
Exibição da latitude e longitude
Exibição da temperatura atual
Tratamento de cidade não encontrada
Consumo de API externa
Alteração do conteúdo da página com JavaScript

Como executar
Baixe ou clone o projeto.
Abra a pasta no VS Code.
Abra o arquivo index.html no navegador.
Digite uma cidade e clique em Buscar.
