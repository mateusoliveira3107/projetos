# ☕ Cafeteria Mateus

Projeto de uma cafeteria desenvolvido para praticar **HTML, CSS e JavaScript**.

O projeto está sendo desenvolvido de forma gradual, adicionando novas funcionalidades conforme os conhecimentos em JavaScript são aprendidos.

## Funcionalidades

* Exibição dos produtos
* Adicionar produtos ao carrinho
* Remover produtos do carrinho
* Escolha da quantidade de produtos
* Cálculo do subtotal dos produtos
* Cálculo do valor total da compra
* Aplicação de descontos
* Carrinho de compras
* Limpar carrinho
* Finalização do pedido
* Exibição do resumo da compra
* Escolha do método de pagamento
* Alteração do conteúdo da página com JavaScript
* Alteração da cor do título

## Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript

## Como executar

1. Baixe ou clone o projeto.
2. Abra a pasta no VS Code.
3. Abra o arquivo `index.html` no navegador.
